# Android T8

Repositorio correspondiente a la octava parte del trabajo de desarrollo de aplicaciones Android.

En esta etapa se desarrollan ejercicios prácticos utilizando **Kotlin, Android Studio y Jetpack Compose**, enfocados principalmente en la **persistencia de datos**, el uso de **Room** y **DataStore**, así como en la creación de aplicaciones que trabajan con información almacenada localmente.

## Contenido

### Ruta 2 - Room

Esta ruta introduce el uso de **Room**, una biblioteca de persistencia de Android que permite trabajar con bases de datos locales de manera estructurada.

* **01 - Conserva los Datos con Room**

  * Introducción a Room.
  * Creación de una base de datos local.
  * Definición de entidades.
  * Uso de DAO para acceder a los datos.
  * Persistencia de información en la aplicación.
  * Proyecto: **Inventory App**.

* **02 - Leer y Actualizar Datos con Room**

  * Lectura de información almacenada.
  * Actualización de registros.
  * Operaciones sobre la base de datos local.
  * Integración de Room con la interfaz de usuario.
  * Proyecto: **Inventory App**.

* **03 - Práctica: App Bus Schedule**

  * Aplicación práctica de Room.
  * Almacenamiento y consulta de información.
  * Desarrollo de una aplicación para consultar horarios de buses.
  * Proyecto: **Bus Schedule App**.

### Ruta 3 - DataStore

Esta ruta introduce **DataStore**, utilizado para almacenar datos pequeños y preferencias de la aplicación de manera persistente.

* **01 - Preferences DataStore**

  * Introducción a DataStore.
  * Almacenamiento de preferencias.
  * Lectura y actualización de datos.
  * Persistencia de configuraciones de la aplicación.
  * Integración con Jetpack Compose.

## Objetivo

Aplicar los conceptos de **persistencia y almacenamiento local de datos** en aplicaciones Android utilizando Kotlin y Jetpack Compose.

Esta etapa permite avanzar desde aplicaciones que manejan información temporal hacia aplicaciones capaces de **guardar, consultar y actualizar datos de manera persistente**, utilizando herramientas como **Room y DataStore**.
